# Roblox Mechanics Library

Mechanics that make strong Roblox games fun, pulled from the weekly deep studies in `radar/breakdowns/`. Each entry is written so it can be applied to any game, not just the one it came from.

Entry format:
**Mechanic name** (status: new / confirmed again in N games)
What it is: one or two lines.
Why it's fun: the feeling it creates (anticipation, greed, surprise, status, social chaos, mastery, comfort).
Seen in: game names with dates.
How to apply it: how to drop it into a different game, with one quick example.
Watch out: when it backfires.
